# kenshi-save-edit

`kenshi-save-edit` is a safe command-line editor for Kenshi save directories.
It does not try to detect Steam, Proton, Kenshi, or an operating system-specific
save location. Every command receives the path to a specific save directory
explicitly.

It can:

- show money, player characters, platoons, and character IDs;
- set money;
- set character skills exactly or raise them to a minimum;
- edit one character, several characters, or a whole platoon;
- heal and feed living characters;
- list and edit faction relations;
- combine independent edits in a single operation.

The editor never changes the input save. Editing requires a separate,
non-existing output directory.

## Requirements

- Python 3.10 or newer
- A completed Kenshi save directory containing `quick.save` and `platoon/`

There are no third-party runtime dependencies. Package metadata is declared in
`pyproject.toml`, so an empty `requirements.txt` is neither needed nor used.

## Install from GitHub

### pipx (recommended)

Install [pipx](https://pipx.pypa.io/) with your operating system's package
manager, then run:

```bash
pipx install 'git+https://github.com/bavadim/kenshi-save-edit.git'
kenshi-save-edit --version
kenshi-save-edit --help
```

To reinstall the latest version from GitHub:

```bash
pipx install --force 'git+https://github.com/bavadim/kenshi-save-edit.git'
```

### Virtual environment and pip

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install 'git+https://github.com/bavadim/kenshi-save-edit.git'
kenshi-save-edit --help
```

On Windows PowerShell, activate the environment with:

```powershell
.\.venv\Scripts\Activate.ps1
```

### Install from a clone

```bash
git clone https://github.com/bavadim/kenshi-save-edit.git
cd kenshi-save-edit
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
kenshi-save-edit --help
```

The Python source is stored in `src/kenshi_save_edit/cli.py`. The installed
`kenshi-save-edit` command has no `.py` extension because it is generated by
the standard Python console-script entry point. The package can also be run
with:

```bash
python -m kenshi_save_edit --help
```

## Find Kenshi saves

Pass the path to one specific save, not only the parent `save` directory.
For example, if the saves directory contains `quicksave`, use:

```text
/path/to/kenshi/save/quicksave
```

### Steam Proton

Kenshi's Steam app ID is `233860`. Inside a Steam library, Proton saves are
normally located at:

```text
<SteamLibrary>/steamapps/compatdata/233860/pfx/drive_c/users/steamuser/AppData/Local/kenshi/save
```

Common Steam library roots include:

```text
~/.local/share/Steam
~/.steam/steam
~/.steam/debian-installation
```

Custom Steam libraries use the same path below their own library root. On
Linux, this command can locate likely Proton save directories:

```bash
find ~/.local/share/Steam ~/.steam \
  -type d \
  -path '*/steamapps/compatdata/233860/pfx/drive_c/users/steamuser/AppData/Local/kenshi/save' \
  2>/dev/null
```

### Native Windows

The usual saves directory is:

```text
%LOCALAPPDATA%\kenshi\save
```

The editor deliberately does not embed any of these locations. Resolve the
path first, then pass the full input and output save paths to the CLI.

## Command interface

```text
kenshi-save-edit list INPUT_SAVE [--platoon NAME ...] [--verbose]
kenshi-save-edit relations INPUT_SAVE
kenshi-save-edit set INPUT_SAVE OUTPUT_SAVE [OPTIONS]
```

Required positional arguments:

| Command | Required arguments |
| --- | --- |
| `list` | Existing `INPUT_SAVE` directory |
| `relations` | Existing `INPUT_SAVE` directory |
| `set` | Existing `INPUT_SAVE` and new, non-existing `OUTPUT_SAVE` directories |

`OUTPUT_SAVE` must differ from `INPUT_SAVE`, cannot be inside it, and must not
already exist. Its parent directory must exist. `--dry-run` still requires
both paths but creates neither files nor directories.

Run the authoritative help for every command:

```bash
kenshi-save-edit --help
kenshi-save-edit list --help
kenshi-save-edit relations --help
kenshi-save-edit set --help
```

## Inspect a save

Show money and all player characters:

```bash
kenshi-save-edit list '/path/to/kenshi/save/quicksave'
```

Show one platoon and stable character IDs:

```bash
kenshi-save-edit list '/path/to/kenshi/save/quicksave' \
  --platoon 'Nameless_1' \
  --verbose
```

Show relations with every faction, including stable faction IDs:

```bash
kenshi-save-edit relations '/path/to/kenshi/save/quicksave'
```

## Edit a save

Every example uses a distinct output path. The input remains unchanged.

Preview an operation:

```bash
kenshi-save-edit set \
  '/path/to/kenshi/save/quicksave' \
  '/path/to/kenshi/save/quicksave_preview' \
  --platoon 'Nameless_1' \
  --all-stats-min 98 \
  --dry-run
```

Set money:

```bash
kenshi-save-edit set \
  '/path/to/kenshi/save/quicksave' \
  '/path/to/kenshi/save/quicksave_money_3000' \
  --money 3000
```

Set selected skills for one character:

```bash
kenshi-save-edit set \
  '/path/to/kenshi/save/quicksave' \
  '/path/to/kenshi/save/quicksave_character_edit' \
  --character 'Beep' \
  --stat strength=80 \
  --stat dexterity=80 \
  --stat toughness=80
```

If character names are duplicated, get an ID with `list --verbose` and use:

```bash
kenshi-save-edit set \
  '/path/to/kenshi/save/quicksave' \
  '/path/to/kenshi/save/quicksave_character_id_edit' \
  --character-id '12582-Nameless_1.platoon-INGAME' \
  --stat strength=80
```

Raise all 33 skills for a platoon to at least 98:

```bash
kenshi-save-edit set \
  '/path/to/kenshi/save/quicksave' \
  '/path/to/kenshi/save/quicksave_group_min98' \
  --platoon 'Nameless_1' \
  --all-stats-min 98
```

Set all skills exactly to 95, heal, and feed a platoon:

```bash
kenshi-save-edit set \
  '/path/to/kenshi/save/quicksave' \
  '/path/to/kenshi/save/quicksave_group_95' \
  --platoon 'Nameless_1' \
  --all-stats 95 \
  --heal \
  --feed
```

Set faction relations by exact display name:

```bash
kenshi-save-edit set \
  '/path/to/kenshi/save/quicksave' \
  '/path/to/kenshi/save/quicksave_relations' \
  --relation 'Holy Nation=0' \
  --relation 'Tech Hunters=10'
```

Faction IDs from `relations` are also accepted. `--reputation` is an alias for
`--relation`:

```bash
kenshi-save-edit set \
  '/path/to/kenshi/save/quicksave' \
  '/path/to/kenshi/save/quicksave_reputation' \
  --reputation '1083-gamedata.base=0'
```

Combine character, money, and faction changes:

```bash
kenshi-save-edit set \
  '/path/to/kenshi/save/quicksave' \
  '/path/to/kenshi/save/quicksave_combined' \
  --platoon 'Nameless_1' \
  --all-stats-min 90 \
  --heal \
  --feed \
  --money 100000 \
  --relation 'Tech Hunters=10'
```

## Options and validation

Character selectors are mutually exclusive:

- `--character NAME`, repeatable
- `--character-id ID`, repeatable
- `--platoon NAME`, repeatable

One selector type is required when using stats, `--heal`, or `--feed`.
Selectors are not needed for `--money` or faction relations.

Changes:

- `--money VALUE`: integer from `0` to `2,000,000,000`
- `--relation FACTION=VALUE` / `--reputation FACTION=VALUE`: `-100` to `100`
- `--stat NAME=VALUE`: set a skill exactly, repeatable
- `--all-stats VALUE`: set all 33 supported skills exactly
- `--stat-min NAME=VALUE`: raise a skill to at least the value, repeatable
- `--all-stats-min VALUE`: raise all 33 skills to at least the value
- `--heal`: heal living selected characters without restoring lost limbs
- `--feed`: fully feed living selected characters

Stat values range from `0` to `100`. Exact and minimum stat modes cannot be
combined. At least one change option is required by `set`.

## Safety model

- The input save is never modified.
- The output must be a new, separate directory.
- The source tree is checked before and after copying; a concurrent source
  change aborts the operation.
- Only existing fixed-width numeric fields are patched.
- Modified files retain their original size.
- Every modified file is parsed and validated before and after writing.
- Writes use a flushed temporary file followed by `os.replace`.
- If editing fails, the incomplete output directory is removed.
- Dead characters are skipped by healing and feeding.
- Healing does not alter death state, lost-limb metadata, or prosthetics.

The editor does not inspect running processes. Avoid live `_current*`
directories and do not use a save while Kenshi is writing it. Create or wait
for a completed named save, run the editor, then load the output directory in
the game.

Save editing is inherently unsupported by the game. Keep independent backups
of important campaigns.
