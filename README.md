# kenshi-save-edit

Безопасный консольный редактор сохранений Kenshi для Linux/Steam Proton.

Скрипт умеет:

- показывать деньги, персонажей и характеристики;
- менять деньги;
- выставлять характеристики точно или поднимать их до минимального значения;
- редактировать одного персонажа или целый отряд;
- лечить живых персонажей без восстановления потерянных конечностей;
- полностью кормить живых персонажей;
- просматривать и менять отношения с фракциями;
- создавать отдельную копию сейва и резервную копию изменяемых файлов.

## Требования

- Linux;
- Python 3.10 или новее;
- Kenshi, установленная через Steam/Proton.

Дополнительные Python-пакеты не нужны.

## Установка

```bash
git clone https://github.com/bavadim/kenshi-save-edit.git
cd kenshi-save-edit
install -Dm755 kenshi-save-edit ~/.local/bin/kenshi-save-edit
```

Убедитесь, что `~/.local/bin` находится в `PATH`:

```bash
kenshi-save-edit --help
```

Скрипт автоматически ищет сейвы в стандартных каталогах Steam. Другой каталог
можно указать глобальным параметром:

```bash
kenshi-save-edit --save-root /path/to/kenshi/save list --save quicksave
```

## Просмотр сейва

Показать деньги и персонажей:

```bash
kenshi-save-edit list --save quicksave
```

Показать только конкретный отряд и стабильные ID персонажей:

```bash
kenshi-save-edit list --save quicksave \
  --platoon 'Безымянные_1' \
  --verbose
```

Показать отношения со всеми фракциями:

```bash
kenshi-save-edit relations --save quicksave
```

## Редактирование

По умолчанию команда `set` не изменяет исходный сейв. Она создаёт рядом новую
копию с именем вида `quicksave_edited_...`.

Предварительно проверить изменения без записи:

```bash
kenshi-save-edit set --save quicksave \
  --platoon 'Безымянные_1' \
  --all-stats-min 98 \
  --dry-run
```

Поднять все 33 навыка каждого участника отряда минимум до 98:

```bash
kenshi-save-edit set --save quicksave \
  --platoon 'Безымянные_1' \
  --all-stats-min 98
```

Выставить все навыки ровно на 95, вылечить и накормить отряд:

```bash
kenshi-save-edit set --save quicksave \
  --copy-as quicksave_group_95 \
  --platoon 'Безымянные_1' \
  --all-stats 95 \
  --heal \
  --feed
```

Изменить отдельные характеристики персонажа:

```bash
kenshi-save-edit set --save quicksave \
  --character 'Грязь' \
  --stat strength=80 \
  --stat dexterity=80 \
  --stat toughness=80
```

Если имена персонажей совпадают, используйте ID из `list --verbose`:

```bash
kenshi-save-edit set --save quicksave \
  --character-id '12582-Безымянные_1.platoon-INGAME' \
  --stat strength=80
```

Установить количество денег:

```bash
kenshi-save-edit set --save quicksave --money 3000
```

Изменить отношения с несколькими фракциями:

```bash
kenshi-save-edit set --save quicksave \
  --relation 'Святая Нация=0' \
  --relation 'Техохотники=10'
```

Фракцию можно указывать по точному имени или по стабильному ID из команды
`relations`. Псевдоним `--reputation` равнозначен `--relation`. Допустимый
диапазон отношений: от `-100` до `100`.

Несколько операций можно объединять в одном вызове:

```bash
kenshi-save-edit set --save quicksave \
  --platoon 'Безымянные_1' \
  --all-stats-min 90 \
  --heal \
  --feed \
  --money 100000 \
  --relation 'Техохотники=10'
```

## Безопасность

- Перед записью скрипт полностью разбирает выбранный сейв.
- Изменяются только существующие числовые поля фиксированной ширины.
- Новая версия файла повторно разбирается и проверяется до и после записи.
- Запись выполняется атомарно.
- Для изменяемого сейва создаётся резервная копия в
  `~/.local/share/kenshi-save-edit/backups/`.
- Если исходный сейв меняется во время копирования, операция отменяется.
- Мёртвые персонажи пропускаются при лечении и кормлении.
- Лечение не изменяет состояние смерти, потерянные конечности и протезы.

Для изменения исходного сейва существует `--in-place`, но безопаснее пользоваться
копией по умолчанию. Если Kenshi или Forgotten Construction Set запущены,
редактирование на месте блокируется. Обход `--allow-running-in-place` следует
использовать только для сейва, который игра в этот момент не записывает, с
последующей загрузкой сейва заново.

Редактирование сохранений выполняйте на свой риск.
